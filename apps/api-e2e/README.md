# api-e2e

Smoke coverage for the starter backend.

## What was done

- Updated the test to validate the learning-oriented describe mode instead of the deleted hello-world placeholder.
- Kept the test lightweight so the workflow can be verified without external services or API keys.

## Why it exists

This package protects the first teaching surface of the repo: the command that explains the monorepo, JSON storage choice, and RAG flow.

## Run

Use `npm run test:e2e`.
